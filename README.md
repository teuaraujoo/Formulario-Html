# 📄 Formulário HTML - Guia Completo de Estudos

## 📍 Sobre o Projeto

Este é um **guia completo e documentado** sobre formulários HTML, criado como material de estudo e consulta. O projeto consiste em um único arquivo HTML contendo **todos os tipos de inputs e tags relacionadas a formulários**, cada um com comentários explicativos detalhados em português.

Diferente de um projeto comum, este é um **manual vivo** onde você pode visualizar e testar cada elemento de formulário diretamente no navegador, entendendo sua funcionalidade e atributos através de exemplos práticos.

## 🎯 Objetivo

- 📚 Servir como **material de referência rápida** para consultas
- 🎓 Facilitar o **aprendizado de formulários HTML** para iniciantes
- 🔍 Documentar **todos os tipos de inputs** e seus atributos
- 💡 Fornecer **exemplos práticos e funcionais** de cada elemento
- 📝 Manter comentários explicativos em **português claro e direto**

## 📚 Conteúdo Documentado

Este guia cobre **aproximadamente 20 tipos de inputs** e elementos de formulário, incluindo:

### 📝 Inputs de Texto
- `text` - Campo de texto simples
- `email` - Campo para endereço de e-mail
- `password` - Campo para senha (oculta caracteres)
- `tel` - Campo para telefone
- `url` - Campo para URL
- `search` - Campo de busca

### 🔢 Inputs Numéricos
- `number` - Campo numérico com controles
- `range` - Slider para seleção de valores

### 📅 Inputs de Data e Hora
- `date` - Seletor de data
- `time` - Seletor de hora
- `datetime-local` - Data e hora local
- `month` - Seletor de mês
- `week` - Seletor de semana

### ☑️ Inputs de Seleção
- `checkbox` - Caixas de seleção múltipla
- `radio` - Botões de opção única
- `select` - Menu suspenso (dropdown)

### 🎨 Inputs Especiais
- `color` - Seletor de cor (color picker)
- `file` - Upload de arquivos
- `hidden` - Campo oculto

### 📤 Botões e Ações
- `submit` - Botão de envio
- `reset` - Botão de limpar formulário
- `button` - Botão genérico

### 📦 Outros Elementos
- `textarea` - Área de texto multilinha
- `label` - Rótulos para inputs
- `fieldset` e `legend` - Agrupamento de campos

## ✨ Características

## 📖 Como Usar Este Guia

### Para Estudar:
1. Clone o repositório
2. Abra o arquivo `index.html` no navegador (recomendado usar Live Server)
3. Leia os comentários no código fonte
4. Teste cada input diretamente no navegador
5. Experimente modificar atributos para ver os efeitos

### Para Consultar:
1. Abra o arquivo HTML em seu editor de código
2. Use `Ctrl+F` para buscar o tipo de input desejado
3. Leia os comentários e atributos documentados
4. Copie o exemplo para seu projeto

## 🚀 Como Executar

1. Clone este repositório:
```bash
git clone https://github.com/teuaraujoo/Formulario-Html.git
```

2. Navegue até a pasta do projeto:


3. Abra o arquivo no navegador:

   - **Opção 2:** Use Live Server no VS Code (recomendado)

## 💡 Filosofia do Projeto

### Por que sem CSS?

Este projeto **intencionalmente não possui estilização** para:
- ✅ Manter o foco 100% no HTML
- ✅ Mostrar o comportamento nativo dos elementos
- ✅ Facilitar a compreensão da estrutura
- ✅ Servir como base limpa para qualquer estilização futura
- ✅ Evitar distrações visuais durante o aprendizado

### Por que tudo em um arquivo?

- ✅ Facilita a busca (Ctrl+F)
- ✅ Permite ver todos os inputs de uma vez
- ✅ Simplifica o download e uso offline
- ✅ Ideal para referência rápida
- ✅ Sem necessidade de navegar entre arquivos
